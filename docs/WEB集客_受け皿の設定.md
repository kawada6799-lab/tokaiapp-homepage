## 1. テーマを反映する（先にこれ）

```bash
node pack-theme.mjs   # build/tokaiapp.zip
```

WordPress の 外観 → テーマ → 新規追加 → テーマのアップロード。
手順は `docs/WordPress反映手順.md`。**反映前にバックアップ**を取ってください。

反映すると、**外観 → カスタマイズ** に「**東海App 設定**」という項目が増えます。
下の 2〜4 は、すべてそこで入れます。zip を上書きしても消えません。

---

## 2. GA4 の測定IDを入れる

### 2-1. 測定IDを取る

1. [Google アナリティクス](https://analytics.google.com/) を開く（Search Console と同じ Google アカウントで）
2. 左下の **管理**（歯車） → **プロパティを作成**
   - プロパティ名: `東海App`
   - タイムゾーン: 日本、通貨: 日本円
3. **データストリーム → ウェブ** を選び、URL に `tokaiapp.com` を入れる
4. 画面に出る **測定ID**（`G-` で始まる10文字前後）をコピー

### 2-2. テーマに入れる

**外観 → カスタマイズ → 東海App 設定 → 「Google アナリティクス（GA4）の測定ID」**
に貼り付けて **公開**。

### 2-3. 動いているか確かめる

1. **ログアウトした状態**（またはシークレットウィンドウ）でサイトを開く。
   ログイン中の閲覧は数えない設計です
2. Google アナリティクスの **レポート → リアルタイム** に、自分のアクセスが出れば完了

### 2-4. Search Console とつなぐ（任意、あると便利）

Google アナリティクスの **管理 → プロダクトのリンク → Search Console のリンク**。
検索語と流入後の動きが1画面で見られるようになります。

---

## 3. OGP画像を入れる

メール・LINE・SNS に URL を貼ったときに出る画像です。

1. **1200×630px** の PNG か JPG を1枚作る。ロゴ＋「クリニックのための医療DX」程度で十分
2. WordPress の **メディア → 新規追加** にアップロード
3. **外観 → カスタマイズ → 東海App 設定 → 「OGP画像」** で選んで **公開**
4. 確認: LINE で自分にURLを送るか、
   [OGP確認ツール](https://developers.facebook.com/tools/debug/) にURLを入れる

> 画像はこのリポジトリに置かないでください（`docs/画像の入れ方.md`）。
> メディアにあれば、zip を上書きしても消えません。

---

## 4. お問い合わせフォームを動かす

手順は `docs/お問い合わせフォームの設置.md` にあります。要点だけ:

1. プラグイン **Contact Form 7** を入れて有効化
2. 同ドキュメントの **2-2〜2-4** の通りにフォームとメールを設定
3. できたショートコードを **外観 → カスタマイズ → 東海App 設定 →
   「お問い合わせフォームのショートコード」** に貼って **公開**
4. **必ず自分で1通送って**、届くことを確認する（迷惑メールフォルダも見る）

これだけで、お問い合わせページの「メールでご相談ください」がフォームに差し替わります。
`pages/contact.html` は書き換えません。

> フォームを入れたら、迷惑送信対策（Honeypot）も同時に。
> 同ドキュメントの「3. 迷惑送信対策」を参照。

## 5. Search Console で見ておくこと

登録は済んでいるので、次の2点だけ。

### 5-1. サイトマップが送ってあるか

左メニュー **サイトマップ** を開き、`https://tokaiapp.com/wp-sitemap.xml` が
「成功しました」になっているか。無ければ、その URL を入力して **送信**。
WordPress が自動で作っているので、プラグインは要りません。

### 5-2. 未登録の6ページが何か

左メニュー **ページ** → 「インデックスに登録されていないページ」の内訳を見る。

- `/wp-admin/` や `?p=123` のようなURL、旧テーマのページ → **放置でよい**
- `/service/douinavi/` や `/price/` など、いまのサイトのページ → 「URL 検査」から **インデックス登録をリクエスト**

判断に迷うURLがあれば、一覧を貼って相談してください。

## テーマが自動で出しているもの（作業は不要）

`wordpress/tokaiapp/inc/seo.php` が、各ページの `<head>` に次を出します。
文言は `pages.json` と同じなので、ページを増やしたら `pages.json` に1行足すだけです。

| 出すもの | 何のため |
|---|---|
| `<title>` と meta description | 検索結果に出る文言。プレビューと同じになる |
| OGP / Twitter カード | URLを貼ったときの見え方 |
| 構造化データ（Organization） | 会社名・URL・ロゴ・所在地（千種区まで）を Google に伝える |
| 構造化データ（Service） | サービス3つ。ドウイナビだけ料金つき（確定済みの金額のみ） |
| 構造化データ（BreadcrumbList） | 検索結果にパンくずが出る |

構造化データに、メールアドレスと電話番号は**入れていません**
（迷惑メール対策と、電話番号を載せない方針のため）。

確認: [リッチリザルト テスト](https://search.google.com/test/rich-results) にURLを入れる。
