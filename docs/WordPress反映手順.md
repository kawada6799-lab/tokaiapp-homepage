# WordPressへの反映手順

## 前提

- **専用テーマ**として動きます。既存テーマとは別物として追加され、
  有効化するまで表示は変わりません
- 投稿・固定ページ・メディア・プラグインの設定には手を触れません

## 1回目（初回）

### 1-1. いまの状態を控える

管理画面 **外観 → テーマ** を開き、
**いま有効になっているテーマの名前をメモ**します。
戻したくなったら、そのテーマを有効化すれば元に戻ります。

可能なら、サーバーのバックアップ（UpdraftPlus 等）も取っておきます。

### 1-2. 固定ページを作る

このテーマは「固定ページのスラッグ」を見て、
`pages/` の中の対応するHTMLを表示します。**先に固定ページの箱を作ります。**

**固定ページ → 新規追加** で、本文は空のまま、次のスラッグで作成します。

| ページ名 | スラッグ | 親 | 表示される中身 |
|---|---|---|---|
| 料金 | `price` | なし | `pages/price.html` |
| 導入事例 | `case` | なし | `pages/case.html` |
| 会社概要 | `company` | なし | `pages/company.html` |
| お問い合わせ | `contact` | なし | `pages/contact.html` |
| お知らせ | `news` | なし | `pages/news.html` |
| サービス | `service` | なし | （親の箱。中身は無くてよい） |
| ドウイナビ | `douinavi` | サービス | `pages/service-douinavi.html` |
| クリニック専用アプリ | `clinic-app` | サービス | `pages/service-clinic-app.html` |
| 医療DX導入支援 | `medical-dx` | サービス | `pages/service-medical-dx.html` |

> 親子にすると URL が `/service/douinavi/` になり、
> テーマは自動で `pages/service-douinavi.html` を探します。
> （階層の `/` を `-` に置き換える規則）

### 1-3. テーマzipを作る

```bash
node pack-theme.mjs
```

`build/tokaiapp.zip` ができます。

### 1-4. アップロードする

**外観 → テーマ → 新規追加 → テーマのアップロード** に zip を入れて
「今すぐインストール」。この時点ではまだ表示は変わりません。

### 1-5. 見え方を確かめる（有効化する前に）

**外観 → カスタマイズ** から「東海App」を選ぶと、公開せずにプレビューできます。

### 1-6. 有効化する

問題なければ「有効化」。

### 1-7. パーマリンクを更新する

**設定 → パーマリンク** を開いて、何も変えずに「変更を保存」。
固定ページのURLが正しく効くようになります。

### 1-8. お問い合わせフォームを差し替える

`pages/contact.html` の `<form>` は見た目だけのひな型です。
**送信されません。** Contact Form 7 などで作ったフォームの
ショートコードに置き換えてください。

置き換える場所: `pages/contact.html` の
`<form class="form" …>` から `</form>` まで。

> ショートコードをHTMLに直接書いても展開されません。
> `wordpress/tokaiapp/functions.php` で `do_shortcode()` を通すか、
> `pages/contact.html` を消して WordPress の編集画面で本文を書く方法があります
> （`pages/` にファイルが無ければ、テーマは自動で本文を使います）。

## 2回目以降の更新

`pages/` や CSS を直したあと:

```bash
node pack-theme.mjs
```

同じzipを **外観 → テーマ → 新規追加 → テーマのアップロード** に入れると
「既存のテーマを置き換える」か聞かれるので、置き換えます。

> CSSとJSのURLにはファイルの更新時刻が付きます（`functions.php` の `filemtime`）。
> アップロードし直せばブラウザのキャッシュは自動で切り替わるので、
> 「直したのに反映されない」が起きにくくなっています。

## 元に戻す

**外観 → テーマ** で、初回に控えたテーマを有効化するだけです。
テーマを削除する必要はありません。

## FTP / ファイルマネージャで置く場合

zipを使わず、`build/tokaiapp/` フォルダを `wp-content/themes/` に
そのまま置いても構いません。中身は同じです。

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| 固定ページが真っ白／WordPressの本文が出る | スラッグが `pages/` のファイル名と合っていない。上の表を確認。親子関係も合わせる |
| 「ページを表示できませんでした」と出る | `pages/` か `parts/` がテーマに入っていない。`node pack-theme.mjs` を実行し直して再アップロード |
| 文字が明朝体になる | Google Fonts が読み込めていない。読めなくてもOS標準のゴシックで表示される |
| 固定ヘッダーが管理バーに隠れる | ログイン中だけの表示。`wordpress/tokaiapp/style.css` で調整済み |
| サービス詳細のURLが `/douinavi/` になる | 固定ページの「親」に「サービス」を指定し忘れている |
| フォームを送信しても何も起きない | ひな型のため。1-8 のとおり差し替える |
