# 国外からのアクセスを制限する

## 先に、いちばん大事なこと

**サイト全体を国外から遮断すると、検索結果に出なくなる可能性があります。**

Googleの検索ロボット（Googlebot）は、主に**米国のIPアドレス**から
ページを読みにきます。サイト全体を「日本以外お断り」にすると、
このロボットも弾かれ、ページが検索結果に載らなくなります。

医療機関に見つけてもらうための導線が切れるので、**既定では次の形**にしています。

| | 国外から |
|---|---|
| 公開ページ（ホーム・サービス・料金など） | **通す** |
| ログイン画面 `wp-login.php` | **止める** |
| 管理画面 `wp-admin` | **止める** |
| XML-RPC `xmlrpc.php` | **止める** |
| REST API の書き込み（POST/PUT/DELETE） | **止める** |
| コメント投稿 | **止める** |
| お問い合わせフォームの送信 | 迷惑メール扱いにする |

不正ログインの試行はほぼすべてこの「止める」側に来るので、
実害はこれで大きく減らせます。

それでもサイト全体を止めたい場合は、下の「サイト全体を止める」を読んでください。

---

## 3つの層があります

止める場所は3つあり、**外側ほど効果が高い**です。

| 層 | 場所 | 効果 | 手間 |
|---|---|---|---|
| 1 | レンタルサーバーの機能 | 高い（PHPが動く前に止まる） | 画面でONにするだけ |
| 2 | Cloudflare などのCDN | 最も高い（サーバーに届く前に止まる） | 設定が少し要る |
| 3 | このテーマの `inc/geo-guard.php` | 低い（WordPressは起動してしまう） | 導入済み |

**層3だけでは不十分です。** WordPressが起動したあとに弾くので、
攻撃の負荷そのものは減りません。テーマを切り替えると外れます。

**まず層1を有効にしてください。** 層3は取りこぼしの受け皿です。

---

## 層1: レンタルサーバーの機能（まずこれ）

国内の主なレンタルサーバーには、**「国外IPアクセス制限」**という機能が
標準で用意されています。管理画面のセキュリティ関連の項目にあります。

| サーバー | だいたいの場所 |
|---|---|
| エックスサーバー | サーバーパネル → WordPressセキュリティ設定 → 国外IPアクセス制限設定 |
| ConoHa WING | サイト管理 → サイトセキュリティ → WordPressセキュリティ |
| ロリポップ | セキュリティ → 海外アタックガード |
| さくらのレンタルサーバ | 各種設定 → WordPressセキュリティ設定 |

> 画面の名称は変わることがあります。見つからないときは、
> ご利用のサーバーのヘルプで「国外IP」「海外IP」で検索してください。

これを有効にすると、多くの場合は次が国外から遮断されます。

- ダッシュボードへのアクセス（`wp-login.php` / `wp-admin`）
- XML-RPC API
- REST API
- コメント・トラックバックの投稿

**公開ページは通常どおり見られる**ので、検索への影響もありません。
まずこれをONにすれば、目的のほとんどは達成できます。

---

## 層2: Cloudflare（さらに強くしたいとき）

サーバーに届く前に止まるので、いちばん効果があります。無料プランで設定できます。

### 設定手順

1. Cloudflare のダッシュボードで tokaiapp.com を選ぶ
2. **Security → WAF → Custom rules** を開く
3. 「Create rule」で次のルールを作る

**ルール名**: 管理画面を国内限定にする

**条件（Expression）**:

```
(not ip.geoip.country in {"JP"}) and (
  http.request.uri.path contains "/wp-login.php" or
  http.request.uri.path contains "/wp-admin" or
  http.request.uri.path contains "/xmlrpc.php"
)
```

**動作（Action）**: Block

4. 保存して有効化

> `/wp-admin/admin-ajax.php` は、公開ページの機能で使われることがあります。
> 何かが動かなくなったら、条件に
> `and not http.request.uri.path contains "/admin-ajax.php"` を足してください。

### 大事な注意 — 直接アクセスを塞ぐ

Cloudflare を入れても、**サーバーのIPアドレスに直接アクセスされると素通り**します。
Cloudflare を経由しないと届かないよう、サーバー側で
**Cloudflare のIPアドレス以外からの接続を拒否**してください。

Cloudflare のIP一覧: https://www.cloudflare.com/ips/

これをやらないと、層2も層3も回避されます（下の「弱点」を参照）。

---

## 層3: このテーマの `inc/geo-guard.php`（導入済み）

テーマに組み込んであります。追加の作業は不要です。

### どうやって国を判定しているか

CDNやサーバーが付ける**国コードのヘッダ**を読んでいます。

- `CF-IPCountry`（Cloudflare）
- `CloudFront-Viewer-Country`（Amazon CloudFront）
- `X-AppEngine-Country`（Google Cloud）
- `GeoIP-Country-Code`（Apache / nginx の GeoIPモジュール）
- `X-Country-Code`（一部のWAF）

**このヘッダが届かない環境では、何もしません。**
「判定できないから全部止める」にすると、設定を変えるたびに
自分が締め出される事故が起きるためです。

いま効いているかどうかは、**WordPressの管理画面の上部に表示**されます。

- 緑の帯 … はたらいています（判定された国コードも出ます）
- 黄色の帯 … 国コードが届いていないため、はたらいていません

### 弱点（必ず読んでください）

**ヘッダは偽装できます。**

サーバーのIPアドレスに直接アクセスできる状態だと、攻撃者は
`CF-IPCountry: JP` というヘッダを自分で付けるだけで、この制限を通り抜けられます。

これはヘッダで国を判定する方式すべてに共通する弱点です。防ぐには:

- **層1（サーバーの機能）を併用する** — サーバー自身がIPを見るので偽装できません
- Cloudflare を使うなら、**Cloudflare のIP以外からの接続を拒否**する（上記）

つまり、**層3は単独では守りになりません。** 必ず層1か層2と組み合わせてください。

### 自分のIPを常に許可する

海外から更新することがある場合や、判定を誤られたときの逃げ道として、
`wp-config.php` に次を書けます。

```php
define('TOKAIAPP_ALLOW_IPS', '203.0.113.10, 198.51.100.20');
```

複数書けます。カンマ区切りで、前後の空白は無視されます。

### サイト全体を止める

冒頭のとおり**検索結果から消える可能性がある**ため、既定では無効です。
それでも止める場合は、`wp-config.php` に次を書きます。

```php
define('TOKAIAPP_GEO_BLOCK_ALL', true);
```

有効にすると、国外からは公開ページも 403 になります。
（日本語と英語で「日本国内からのみご利用いただけます」と表示されます）

**この設定を入れる前に、検索経由の流入を捨ててよいか確認してください。**

---

## 確認のしかた

### 効いているか

1. WordPressの管理画面を開き、上部の帯を見る（緑なら効いています）
2. 緑なら、判定された国コードが日本 `JP` になっているかを確認

### 国外から見たらどうなるか

自分では国外からアクセスできないため、次のいずれかで確認します。

- VPNサービスで海外のサーバーに接続してから `tokaiapp.com/wp-login.php` を開く
- 海外にいる知人に開いてもらう
- オンラインの「海外からサイトが見えるか」を確かめるサービスを使う

### 締め出されてしまったら

1. **層1（サーバーの機能）の場合** — サーバーの管理画面から解除できます。
   サーバーの管理画面は WordPress とは別なので、そちらには入れます
2. **層3の場合** — FTPやファイルマネージャで
   `wp-content/themes/tokaiapp/inc/geo-guard.php` の中身を空にすれば止まります
3. **Cloudflare の場合** — Cloudflare のダッシュボードでルールを無効にします

---

## まとめ

- [ ] **層1**: レンタルサーバーの「国外IPアクセス制限」をONにする ← まずこれ
- [ ] 層3が効いているか、WordPressの管理画面の帯で確認する
- [ ] （さらに強くするなら）層2: Cloudflare のWAFルールを作る
- [ ] （層2を使うなら）Cloudflare のIP以外からの接続を拒否する
- [ ] 自分のIPを `TOKAIAPP_ALLOW_IPS` に入れておく
- [ ] サイト全体の遮断は、検索への影響を理解したうえで判断する
