# デザイン方針

Artifact「東海App リニューアル設計」で決めたことの、実装側の記録。

## 配色

現行ロゴ「TA」の濃紺とブルーを、そのままブランドカラーにしています。
色は役割ごとに固定します。

| 役割 | 色 | 変数 |
|---|---|---|
| ヘッダー・見出し・濃い面 | `#062850` ネイビー | `--navy` |
| フッター背景・CTA帯 | `#041d3b` ディープ | `--navy-900` |
| リンク・アイコン・強調 | `#076aa3` ブルー | `--blue` |
| セクション背景 | `#e8f1f8` ペールブルー | `--blue-100` |
| **CTA専用** | `#e0803a` オレンジ | `--orange` |

**オレンジは問い合わせ導線だけに使います。**
「オレンジ＝問い合わせ」と閲覧者に学習させるための配色なので、
見出しや装飾に流用すると効果が薄れます。

### サービス識別色

サービス詳細3ページは同じ骨格で、この色だけが変わります。
ページヘッダーのグラデーションと、カード上端のバーに出ます。

| サービス | 色 | 変数 |
|---|---|---|
| クリニック専用アプリ | `#076aa3` | `--svc-app` |
| 医療DX導入支援 | `#17876f` | `--svc-dx` |
| ドウイナビ | `#e0803a` | `--svc-douinavi` |

> ドウイナビ**製品**のUI色はティール `#0f766e` です（患者画面・説明動画で使用）。
> サイト上の識別色オレンジとは別物なので、混同しないこと。
> ティールを使ってよいのは、患者画面の再現モック（`.phone`）の中だけです。

## 書体

- 見出し・本文: **Noto Sans JP**
- 英数字・数値: **Barlow**（`.num` `.stat__num` `.plan__price` など）
- 本文行間 **1.9** — 日本語は欧文の定石より広く取る
- 見出しは `clamp()` で 1.9rem → 3.2rem に可変

## 見出しの形

英字ラベル ＋ 日本語見出しの2段組みで統一します。

```html
<div class="sec-head">
  <p class="label">Services</p>
  <h2 class="sec-title">3つのサービスで、…</h2>
</div>
```

## ホームの並び順

「課題に気づく → サービスを知る → 信頼する → 費用感を掴む → 動く」の順。

B2Bでは**費用が分からないことが最大の離脱要因**なので、
料金の目安をホームの時点で見せます。

| # | ブロック | 意図 |
|---|---|---|
| 01 | ヘッダー | 相談ボタンを常時表示。スクロールで縮小して追従 |
| 02 | ファーストビュー | ロゴのグラデーションを背景に |
| 03 | 課題提起 | 「自分のことだ」と思わせる。ここを飛ばすと以降が刺さらない |
| 04 | 3サービス | 識別色を上端バーで提示 |
| 05 | 選ばれる理由 | 個人規模だからこその強みを4点 |
| 06 | 料金 | 費用不明は最大の離脱要因。ホームの時点で金額を見せる |
| 07 | 導入の流れ | 「相談は無料」を明示して心理的な障壁を下げる |
| 08 | お知らせ | 更新されている＝生きている会社であることの証明 |
| 09 | CTA帯 | 全ページ共通 |
| 10 | フッター | 所在地を明記。医療系では実在性の提示が信頼に効く |

> 設計案にあった「数値実績」「導入事例」は、実績がまだ無いため外しています。
> 出せるようになったら戻せます（`docs/要確認リスト.md` の E）。

## サービス詳細の共通骨格

3ページとも同じ順序にします。テンプレートを共通化でき、
閲覧者も2つ目以降を同じ読み方で理解できます。

1. ページヘッダー（パンくず＋識別色のグラデーション）
2. 課題提起 — そのサービスが解く問題に限定して3点
3. 製品紹介 — 画面を左、説明とダウンロードを右
4. 機能・ステップ — ドウイナビは5ステップ、他は機能一覧
5. 導入効果 — 数値を最大サイズで
6. よくある質問 — 検討段階の不安を先回りで潰す。SEOにも効く
7. CTA帯（共通）

## モバイル

医療系B2Bでも、閲覧の6〜7割はスマートフォンです。

| 決めごと | 実装 |
|---|---|
| 画面下部に問い合わせバーを常時固定 | `.sticky-cta` |
| CTA帯が見えている間はバーを隠す | `main.js` の 4。同じ導線が二重に出るのを防ぐ |
| メニューを開いても相談ボタンは最上部 | `.nav__cta-wrap { order: -1 }` |
| フォームは1カラム | 医療機関の担当者は年齢層が高めのため、タップ領域を大きく取る |

## その他

- 見出しの折り返しに `text-wrap: balance` と `word-break: auto-phrase`
  （非対応ブラウザでは無視されるだけ）
- `prefers-reduced-motion` に対応。動きを減らす設定では演出を止める
- 印刷用スタイルあり
- 画像ファイルは使っていません。端末モック・管理画面枠はCSSとインラインSVG

## 料金の見せ方

プランを3つに分けず、**1本の料金**で出しています。

- 初期費用 55,000円（税込） / 月額 11,000円（税込）
- 制作物や個別開発は「別途お見積り」として分ける

「上位プランでないと使えない」という形にすると、本当に必要な機能を
選びにくくなる — というのが、分けない理由です。
`.price-single` がその見せ方の部品で、金額だけネイビーの面に置いて
Barlow で大きく出しています。

## 連絡先

**電話番号は載せていません。** 連絡先はメールのみです。
ヘッダー上段・CTA帯・フッター・お問い合わせ・会社概要・プライバシーポリシーの
6箇所に同じアドレスが出るので、変更するときは全部直してください。
