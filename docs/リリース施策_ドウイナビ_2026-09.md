## C. 9月中（土台づくり）

### C-1. 導入事例を1件つくる ★これが最強のコンテンツ

すでにお使いの先生に、掲載の許諾をお願いしてください。

必要なもの:
- 医院名（**匿名可**。「名古屋市内・消化器内科」でも成立します）
- 導入前の課題（具体的な場面で）
- 導入後の変化（数値があると強い。無ければ言葉でよい）
- 担当者コメント
- 写真（外観・院内・実際の画面）

1件できたら、サイトに事例ページを作ります（ひな型は用意済みです）。

### C-2. Googleビジネスプロフィールに登録する

「名古屋 クリニック 医療DX」のような検索で出るようになります。無料です。

### C-3. OGP画像を用意する

メールやSNSにURLを貼ったとき、いまは画像が出ません。
1200×630px を1枚用意すれば、見え方が大きく変わります。

### C-4. 検索対策（SEO）

サイトのページは揃っているので、土台はできています。次にやるなら:

- Yoast SEO で、各ページの説明文（メタディスクリプション）を書く
- Google Search Console に登録し、サイトマップを送る
- 狙う言葉の例:
  「検査説明 動画」「内視鏡 説明 効率化」「クリニック 医療DX 名古屋」
  「WEB問診 クリニック 名古屋」

## E. やらなくてよいこと（いまは）

| | 理由 |
|---|---|
| リスティング広告 | 医療系B2Bはクリック単価が高く、母数も小さい。事例が無い段階では費用対効果が悪い |
| プレスリリース配信（PR TIMESなど） | BtoB医療では拾われにくく、費用に見合いにくい |
| SNS運用（X・Instagram） | 医師は仕事の情報をSNSで探しません。労力に対して返りが薄い |
