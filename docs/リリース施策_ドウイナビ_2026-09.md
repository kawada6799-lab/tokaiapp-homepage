## 補足：ネットでのリード獲得について

「アナログな動きばかりでは」という疑問はもっともです。整理しておきます。

### なぜネットだけでは取りにくいのか

1. **検索する人がいない**
   院長は「検査説明 動画」とは検索しません。困ってはいても、
   「そういう仕組みがある」と知らないので、**検索語そのものが生まれない**。
   需要が顕在化していない領域です

2. **母数が小さい**
   全国でも診療所は10万件規模で、そのうち内視鏡を日常的に行うのは一部。
   さらに名古屋周辺に絞ると、検索ボリュームはごくわずかになります

3. **決裁者がウェブを見ない**
   院長は診療中で、能動的にサービスを探す時間がありません

4. **医療は信頼が先**
   知らない会社からは買いません。ウェブだけで初回接触から契約までは、まず届きません

### では、ネットは何のためにあるのか

**紹介・勉強会・展示会で名前を聞いた人は、必ず検索します。**
そのときに、ちゃんとした会社に見えるかどうかで結果が変わります。

いまサイトを整えたことの価値の大部分はここにあります。
「アナログで動く」と「サイトが要らない」は別の話で、
**アナログで動くからこそ、受け皿が要ります。**

### そのうえで、ネットからも取れるもの

効きそうな順に並べます。

#### 1. IT導入補助金への登録 ★調べる価値がいちばん高い

クリニックは**補助金は能動的に検索します。**
「クリニック IT導入補助金」「電子問診 補助金」は、
数少ない「向こうから探しに来る」検索です。

- ドウイナビが補助金の対象ツールとして登録できれば、
  **導入のハードルが下がるうえに、カタログ経由で見つけてもらえます**
- 登録には、IT導入支援事業者としての申請が必要です
- **対象になるかどうかは要確認**です。まず制度の要件を調べることをおすすめします

これは「集客」と「値引き」を同時に解決する可能性があるので、
他のネット施策より先に調べる価値があります。

#### 2. 課題側のキーワードで記事を書く

製品名ではなく、**院長・事務長が実際に困って検索する言葉**を狙います。

| 狙う言葉 | なぜ |
|---|---|
| 大腸内視鏡 前処置 説明 患者 理解 | 実際に困って検索される |
| クリニック 問診 電子化 費用 | 費用を調べる段階の人 |
| 内視鏡 検査説明 時間 短縮 | 課題が言語化できている人 |
| クリニック IT導入補助金 | 上記のとおり |

月1本で十分です。検索数は少ないですが、**競合も少ない**ので上位を取りやすく、
読む人はほぼ全員が見込み客です。

#### 3. 説明動画のサンプルを公開する（YouTube）

**本業が動画制作なので、これはコストが低く、説得力が高い施策です。**

- 特定のクリニックに依存しない、一般的な検査説明の動画を1本作って公開する
- 「これがドウイナビで作れるもの」を、言葉ではなく現物で見せられる
- 患者向けの検索（「大腸内視鏡 検査 流れ」など）でも拾われます
- サイトのサービス詳細ページに埋め込めば、滞在時間も伸びます

いまサイトには**製品の画面が1枚もありません**（CSSで描いた再現のみ）。
実物の動画があると、ここが一気に埋まります。

#### 4. Googleビジネスプロフィール

無料。「名古屋 医療DX」のような地域検索に出ます。所在地を公開しているので登録できます。

#### 5. 医療系メディアへの寄稿・掲載

開業医向けのメディアやポータルに、記事として載せてもらう。
自社サイトより読者が多く、信頼も借りられます。

### 期待値の目安

正直に言うと、**SEO単体では月に数件の問い合わせが取れれば上出来**です。
しかも効き始めるまで半年〜1年かかります。

一方で、紹介からの1件は**ほぼ決まります**。
だから優先順位は「紹介 → 受け皿を整える → ネットは長期で仕込む」になります。

### いま順番をつけるなら

1. **IT導入補助金の対象になれるか調べる**（当たれば効果が大きい）
2. **説明動画のサンプルを1本公開する**（本業の強みがそのまま使える）
3. 導入事例を1件つくる（ネットでもアナログでも効く）
4. Googleビジネスプロフィール登録
5. 課題キーワードの記事を月1本
