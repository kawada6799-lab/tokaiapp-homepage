# 文言の直し方

「ここの1行だけ変えたい」というときの手順です。**3つの方法**があり、
それぞれ長所と落とし穴が違います。

---

## 方法1: WordPressの管理画面で直す（いちばん手軽）

**外観 → テーマファイルエディター** から、テーマの中のHTMLを直接編集できます。

1. **外観 → テーマファイルエディター**
2. 右上の「編集するテーマを選択」で **東海App** を選ぶ
3. 右側のファイル一覧から、直したいファイルを選ぶ

| 直したい場所 | ファイル |
|---|---|
| ホームの文言 | `pages/home.html` |
| ドウイナビのページ | `pages/service-douinavi.html` |
| 料金 | `pages/price.html` |
| 会社概要 | `pages/company.html` |
| ヘッダーのメニュー | `parts/header.html` |
| フッター | `parts/footer.html` |
| CTA帯（全ページ共通） | `parts/cta.html` |
| **写真の差し替え** | `assets/css/photos.css` （→ docs/画像の入れ方.md） |

4. 文字を直して、下の **ファイルを更新** を押す

### ⚠️ 落とし穴：zipを上書きすると消えます

**ここで直した内容は、次にテーマのzipをアップロードした時点で消えます。**
zipの中身で丸ごと上書きされるためです。

なので、この方法で直したら **必ず次のどちらかをしてください。**

- チャットで「◯◯を△△に変えた」と伝える（リポジトリ側にも反映します）
- または、GitHub で同じ箇所を自分で直す（方法2）

### ⚠️ タグを壊さないように

HTMLなので、`<p>` や `</div>` を消してしまうと表示が崩れます。
**文字だけを直し、`<` と `>` で囲まれた部分は触らない**ようにしてください。

崩れてしまったら、zipを上書きアップロードすれば元に戻ります。

### 「テーマファイルエディター」が見つからないとき

セキュリティ設定でファイル編集が止められていることがあります。
その場合は方法2か方法3を使ってください。

---

## 方法2: GitHub のサイト上で直す

[リポジトリ](https://github.com/kawada6799-lab/tokaiapp-homepage) を開いて、
ファイルを選び、右上の**鉛筆アイコン**で直接編集できます。

1. `pages/` か `parts/` の中から、直したいファイルを開く
2. 鉛筆アイコン → 文字を直す
3. 下の **Commit changes** を押す

**こちらが正しい保存先**です。消えません。

ただし、**これだけでは本番サイトは変わりません。**
本番に反映するには zip を作り直す必要があります（方法3、またはチャットで依頼）。

---

## 方法3: 手元の Claude Code で直す（本来の運用）

リポジトリを手元に置いて、Claude Code で開きます。

```bash
git clone https://github.com/kawada6799-lab/tokaiapp-homepage
cd tokaiapp-homepage
```

あとは Claude Code に「ホームのキャッチコピーを◯◯に変えて」と伝えれば、
該当箇所を直してくれます。確認と反映は次の2つだけです。

```bash
node build.mjs        # preview/index.html をブラウザで開いて確認
node pack-theme.mjs   # build/tokaiapp.zip ができる → WordPressにアップロード
```

`git push` すれば GitHub にも残ります。

**この方法なら、直した内容が消えることはありません。**

---

## どれを使えばいいか

| 状況 | おすすめ |
|---|---|
| 誤字を1文字直したい。すぐ直したい | **方法1**（あとで伝えてください） |
| 文章をまとめて書き換えたい | **方法3** |
| 手元にPCが無い。とりあえず記録だけ残したい | **方法2** |
| ページを増やしたい・デザインを変えたい | チャットで依頼してください |

---

## 直してはいけないもの

次の3つは、直すと表示が壊れます。

1. **`data-mail="info"` `data-mail-domain="tokaiapp.com"`**
   — メールアドレスを分けて置いてあります（迷惑メール対策）。
   アドレスを変えるときは、この2つの値を直します
2. **`class="..."` の中身** — デザインの指定です
3. **`pages/` のファイル名** — WordPressの固定ページのスラッグと対応しています。
   名前を変えると、そのページが表示されなくなります

## 色や余白を変えたいとき

`assets/css/tokens.css` の中の数値を変えると、サイト全体の印象が変わります。
ただし影響範囲が広いので、変えたい場合はチャットで相談してください。
