## E. セキュリティ（公開前に）

国外アクセス制限は**テーマ側に導入済み**ですが、
**それだけでは守りになりません**（ヘッダを偽装できるため）。

- [ ] レンタルサーバーの「**国外IPアクセス制限**」をONにする ← まずこれ
- [ ] WordPressの管理画面の上部の帯が**緑**になっているか確認する
- [ ] 自分のIPを `wp-config.php` の `TOKAIAPP_ALLOW_IPS` に入れておく
- [ ] （Cloudflareを使うなら）Cloudflare以外からの接続を拒否する

手順は `docs/セキュリティ_国外アクセス制限.md` にまとめてあります。

> **サイト全体の遮断は既定で無効**にしています。有効にすると
> Googleの検索ロボット（主に米国IP）も弾かれ、検索結果から消える可能性があります。
